# 보류(2번) 항목 설명

카탈로그에서 2번으로 표시한 51개 항목을 쉽게 풀어 쓴 문서다. 각 항목마다 무엇인지, 언제 쓰는지, 그리고 이미 고른 1번 항목과의 관계를 보고 추천을 붙였다.

추천 표기

| 표기 | 뜻 |
| --- | --- |
| 포함 권장 | 1번으로 고른 기능이 이것에 기대거나, 비용이 거의 없고 쓸모가 큼 |
| 취향 | 쓰는 사람에 따라 갈림. 설명을 보고 결정 |
| 나중 | 지금 넣을 필요 없음. 기반이 완성된 뒤 판단 |
| 불필요 권장 | 고른 방향(사진 위주, 영상 제외, 내장 최소)과 맞지 않음 |

먼저 알아둘 것

- 1번으로 고른 웹 원격 제어, 3D LUT 실시간 교체, FilmLab 은 telnet, 웹 서버, LUT 도구 같은 하위 부품이 있어야 동작한다. 아래에서 이런 부품은 포함 권장으로 표시했다.
- 3번으로 영상 관련을 모두 뺐으므로 영상 쪽 2번 항목은 대부분 불필요 권장이 된다.

## 4. 타임랩스

| 항목 | 무엇인가 | 언제 쓰나 | 추천 |
| --- | --- | --- | --- |
| Wake Lapse | 지정한 시간만큼 잠들었다가 깨어나 타임랩스를 시작한다 | 새벽 일출을 밤에 미리 세팅해 두는 경우 | 취향. 타임랩스를 찍는다면 포함 |
| Ramping | 타임랩스 중 노출을 서서히 바꾼다 | 해 질 녘에서 밤으로 넘어가는 장면 (홀리그레일) | 취향. 타임랩스를 찍는다면 포함 |
| Mod Lapse | 간격, 장수, 화면 끄기, 끝나면 전원 끄기를 설정하는 인터벌 촬영 프로그램 | 일반 타임랩스. 순정 인터벌 기능보다 옵션이 많음 | 취향. 셋 중 하나만 고른다면 이것 |
| 전원 절약 끄기/켜기 | 30분 후 자동 꺼짐을 끈다 | 몇 시간짜리 타임랩스 | 타임랩스를 넣으면 포함 권장, 아니면 불필요 |

정리하면 타임랩스를 찍는지 하나만 결정하면 된다. 찍는다면 Mod Lapse 와 전원 절약 끄기는 넣고, Wake Lapse 와 Ramping 은 쓸 일이 있는지 본다. 무음 전자셔터(1번)와 함께 쓰면 기계 셔터 수명을 아낄 수 있다.

## 9. 색과 필름 시뮬레이션

1번으로 FilmLab, 3D LUT 실시간 교체, 내장 4종 LUT 전환을 골랐다.

| 항목 | 무엇인가 | 추천 |
| --- | --- | --- |
| 레시피 7차원 즉시 반영 | FilmLab 레시피를 고르는 즉시 화면에 반영. 대신 ISP 펌웨어(p7 파티션)를 고쳐 써야 한다 | 불필요 권장. 원칙 2번(파티션 쓰기 금지)과 충돌. 없으면 화면 마법사에서 사용자1 을 한 번 눌러 주는 단계가 생길 뿐 |
| .cube 변환기 | 인터넷에서 받은 .cube 필름 LUT 를 카메라용 형식으로 바꾼다 | 포함 권장. 1번의 3D LUT 실시간 교체에 넣을 표를 만드는 도구. PC 에서 변환해도 되지만 카메라 안에서 되면 SD 에 .cube 만 넣으면 됨 |
| 사용자1/2/3 이름을 레시피 이름으로 | 순정 메뉴의 "사용자1" 글자를 "Portra 400" 처럼 바꾼다 | 나중. NXWA 에서도 실험 단계이고 카메라 앱에 파일을 덮어 마운트하는 방식이라 원칙과 경계선 |
| 미공개 NX-KS3 LUT 파일 | KinoSeed 가 남긴 .cube 한 개. "copyrighted, do not distribute" 표기 | 불필요 권장. 라이선스상 배포 불가, 쓰는 코드도 없음 |

주의: 1번으로 고른 두 항목은 위험도가 중간이다.

- 3D LUT 실시간 교체는 /dev/mem 으로 메모리를 직접 쓴다. 주소가 틀리면 카메라가 멈추고 배터리를 빼야 한다. 공개된 지 하루 된 기능이라 몇 주 지켜본 뒤 넣는 것을 권한다.
- 내장 4종 LUT 전환과 LUT 진단 스크립트들은 NXWA 에서도 "실험용, 값 의미 미확인"으로 표시된 것들이다. 실시간 교체가 정식 방법이 되면서 대부분 필요 없어졌다. 진단(상태 읽기)만 남기고 전환은 실시간 교체로 대체하는 것을 권한다.
