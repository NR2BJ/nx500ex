# nx500ex 로드맵 초안

이 문서는 docs/research/2026-10-18-feature-and-script-catalog.md 의 선택 결과를 받아 채우는 계획서다. 지금까지 대화에서 정한 원칙과 단계 골격만 먼저 적어 두었다.

## 1. 원칙

1. 내장 변경은 bluetoothd 래퍼 한 파일과 /opt/usr 아래 디렉터리로 한정한다. 루트 파일시스템에 다른 파일을 쓰지 않는다.
2. 하이버네이션 스냅샷 재생성, 파티션 dd, p7 펌웨어 패치는 하지 않는다.
3. 기능 스크립트는 SD 카드에서 자유롭게 넣고 뺄 수 있어야 한다. 카드가 없으면 순정처럼 동작한다.
4. 키 감지 바이너리는 내장에 두어 전원 OFF/ON 후에도 살아 있게 한다.
5. auto 스크립트는 파일명 번호 순으로 실행된다. 가벼운 설정을 앞에, 무거운 서비스를 뒤에 두고 무거운 것은 백그라운드로 띄운다.
6. 대상 펌웨어는 NX500 1.12 하나로 시작한다. NX1 은 나중에 판단한다.
7. 공개 저장소로 운영하고 상류 코드를 쓰는 부분은 AGPL-3.0 을 따른다.

개발 도구 (카메라 기능 아님): prefman 덤프 해석기, 공유 라이브러리 함수 직접 호출(nxcalldyn), gdb 원격 디버깅, PNG 버튼 예제, di-camera-app 정적 분석 스크립트.

보류 (나중에 다시 판단): NXUI 대체 메뉴, CPU performance 모드, WiFi 로 웹 프런트 푸시, 원격 저장(nx-netfs), 이메일/SNS 서버, di-camera-app 명령 브리지(NXWA 에서 멈춤 경고가 있는 실험 단계).

제외: 영상 관련 전부, 포커스 풀, DEV 메뉴, 시네마 가이드, AP 모드, 여러 대 동기 제어, Hibernate/Sleep, 스왑, 펌웨어 알림 조작, 블루투스 복원 기능(래퍼 설계로 해결), 7차원 즉시 반영(A2), p7 백업/플래시, 사용자 슬롯 이름 변경, NX-KS3 LUT 파일, 내장 LUT 전환, 카메라 내 브라우저, JPEG/RAW 토글, 포커스 위치 버튼, 부팅 시 포커스 복원.
