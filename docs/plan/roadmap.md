# nx500ex 로드맵 초안

이 문서는 docs/research/2026-10-18-feature-and-script-catalog.md 의 선택 결과를 받아 채우는 계획서다. 지금까지 대화에서 정한 원칙과 단계 골격만 먼저 적어 두었다.

## 1. 원칙

1. 내장 변경은 bt-stack-up.sh 래퍼 한 파일과 원본 이름 변경으로 한정한다 (v2, 2026-10-19). bluetoothd 는 건드리지 않는다. /opt/usr 는 실측 결과 필요할 때만 keyscan 하나를 둔다.
2. 하이버네이션 스냅샷 재생성, 파티션 dd, p7 펌웨어 패치는 하지 않는다.
3. 기능 스크립트는 SD 카드에서 자유롭게 넣고 뺄 수 있어야 한다. 카드가 없으면 순정처럼 동작한다.
4. 키 감지 바이너리도 SD 에서 실행한다. 켤 때마다 블루투스 래퍼가 다시 띄운다.
5. auto 스크립트는 파일명 번호 순으로 실행된다. 가벼운 설정을 앞에, 무거운 서비스를 뒤에 두고 무거운 것은 백그라운드로 띄운다.
6. 대상 펌웨어는 NX500 1.12 하나로 시작한다. NX1 은 나중에 판단한다.
7. SD 에 기록을 남기는 스크립트는 쓰기 뒤에 sync 한다. 전원 OFF 나 카드 분리 때 기록이 사라지지 않게 한다.
8. 공개 저장소로 운영하고 상류 코드를 쓰는 부분은 AGPL-3.0 을 따른다.

보류 (나중에 다시 판단): NXUI 대체 메뉴, CPU performance 모드, WiFi 로 웹 프런트 푸시, 원격 저장(nx-netfs), 이메일/SNS 서버, di-camera-app 명령 브리지(NXWA 에서 멈춤 경고가 있는 실험 단계).
