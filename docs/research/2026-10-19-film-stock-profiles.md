# 필름 레시피를 위한 실제 필름 특성 조사 (2026-10-19)

NXWA 레시피 68개는 근거 없는 근사값이 섞여 있었다 (예: Kodachrome 25 와 64 가 전혀 다른 방향). 그래서 실제 필름 특성을 웹 자료로 조사하고, 우리가 바꿀 수 있는 값(화면 마법사 7가지 + 색온도)으로 다시 정했다. 결과는 sd/nx500ex/scripts/film/recipes.txt.

자료는 대부분 스캔 결과를 근거로 한 리뷰라 같은 필름도 현상소와 스캐너에 따라 다르게 보인다. 데이터시트로 확인한 것은 Portra 800, Tri-X, Pan F Plus, Rollei CN 200, Reala 기술 논문뿐이다.

## 1. 원칙

## 4. 시험 촬영으로 확인할 것

- 채도와 대비 한 단계의 실제 크기. 극단값(Velvia 50 채도 15, 크로스 프로세스 대비 15)은 클리핑을 보고 1 낮출 수 있다.
- 흑백에서 게인이 흑백 변환 전에 적용되는지: 빨간 피사체를 R 120 과 R 80 으로 비교.
- 색조 9, 11 의 방향.
- CineStill 800T 가 너무 파라면 3800~4200K.

## 7. 보정 촬영 결과 (2026-10-19, SAM_0602~0617, 16-50S, 손으로 들고 모니터 색표)

방법: 모니터에 calib_chart.png, scripts/calib.sh 로 값 하나씩 바꾼 16장, tools/film/calib_analyze.py 로 칸 가운데 40% 의 평균 색(Lab)을 기준 사진과 비교. 손으로 들고 찍어 노출이 장마다 조금 달랐다 (변하지 않아야 할 회색 L 이 기준 대비 +1~+4). 그 정도는 잡음으로 본다.

| 설정 | 결과 |
| --- | --- |
| 채도 5 / 15 | 색 칸 채도 0.55배 / 1.41배. 한 단계 약 8~11% |
| 대비 5 / 15 | 밝은 회색 L -2.5 / +7, 어두운 회색 L +6.6 / -2.4, 채도도 0.86 / 1.17배. 한 단계 밝은 쪽 L 약 1.4 |
| R 90 / 110 | 회색 a -4.0 / +4.1 (초록-청록 / 빨강 쪽), 밝기 변화는 잡음 수준 |
| G 110 | 회색 a -5.3, b +4.1 (노란 초록 쪽) |
| B 90 / 110 | 회색 b +4.8 / -3.4 (노랑 / 파랑 쪽) |
| 색조 8 / 12 | 색 칸 색상각 평균 -7.5도 / +7.5도 (칸에 따라 2~24도). 한 단계 약 3.8도. +는 빨강 -> 주황 -> 노랑, 초록 -> 청록, 파랑 -> 보라 방향 |
| 흑백 R 120 / 80, B 120 | 빨강 칸 밝기가 거의 그대로(46.6 -> 46.9 / 46.1). 컬러 필터처럼 작동하지 않는다 |

결론과 레시피 수정:
- 게인 10% 가 회색을 Lab 약 4 만큼 기울인다. 처음 레시피의 ±3~4 는 Lab 1.5 정도라 거의 안 보였다. 필름 성향(따뜻함, 초록, 시안)을 회색이 Lab 2~6 기울도록 다시 잡았다 (예: Portra 400 R 102 B 94, Gold 200 R 104 B 88, Pro 400H R 96 G 103 B 108).
- 채도와 대비는 한 단계가 꽤 커서 처음 값 유지 (Velvia 50 채도 15 = 1.4배).
- 흑백은 게인을 모두 100 으로 (필터 효과 없음).
- 색조는 방향과 크기를 알게 됐지만 칸마다 차이가 커서 아직 10 유지.

## 9. 2차 보정 촬영 (2026-10-19, SAM_0602~0619 두 번째 묶음, 같은 방법)

반복성: 1차와 거의 같다. 채도 5/15 = 0.55/1.38배 (1차 0.55/1.41), 대비 5/15 채도 0.85/1.15배, R 90/110 회색 a -3.6/+3.6 (1차 -4.0/+4.1), G 110 a -5.0 b +3.6, B 90/110 b +4.8/-3.1, 색조 8/12 = -7.6/+7.3도. 흑백 R 120/80, B 120 은 이번에도 필터 효과가 없다 (R 80 이 전체를 조금 어둡게 할 뿐).

토닝 시험 (R 110 G 100 B 85, 채도 2 와 4)

| 장 | 회색 칸 a / b (밝은 쪽 -> 어두운 쪽) | 색 칸 채도 (기준 47.2) |
| --- | --- | --- |
| 기준 | +1~+4 / +1~+2 (모니터 기운) | 47.2 |
| 흑백 (채도 0) | 0 / 0 | 0 |
| tone_s2 | -0.5~+1.1 / +2.5~+3.0 | 12.3 (26%) |
| tone_s4 | -0.5~+1.8 / +4.5~+5.9 | 22.1 (47%) |
| 비교: R 110 (채도 10) | +3~+9 / +2~+3 | 48.2 |
| 비교: B 90 (채도 10) | -1~+2 / +6~+8 | 48.2 |

해석

- 채도 설정이 게인으로 낸 회색의 기울기까지 같은 비율로 줄인다. 채도 2 에서 회색 기울기는 채도 10 일 때의 약 30% 다. 화면 마법사 안에서 게인이 채도 앞에 적용된다는 뜻이다 (채도 0 에서 게인이 효과가 없는 것과 같은 이유).
- 그래서 채도를 낮춰 흑백에 가깝게 할수록 색도 빠지고, 색을 입히려 채도를 올리면 장면 색이 돌아온다. tone_s4 는 회색이 b +5 (옅은 노랑)인데 장면 색이 47% 남아 토닝된 흑백이 아니라 바랜 컬러로 보인다. 실제 세피아 인화는 회색이 b +12~+20 정도라 닿지 못한다.
- 결론: 세피아, 셀레늄 토닝은 화면 마법사로 안 된다. 레시피에서 빼고 LUT 목록에 넣었다. 보정 촬영의 tone 두 장도 뺐다 (16장).
- 채도가 낮은 레시피는 게인 기울기가 채도 비율만큼 줄어드는 것을 감안해 게인 차이를 키웠다: Metropolis 100 104 92 -> 100 106 86 (채도 4, 약 0.47배), 바랜 인화 104 100 92 -> 105 100 90 (채도 7). 채도 8~9 인 레시피(Portra 160, Pro 400H, Eterna 500T, SX-70)는 0.8~0.9배라 그대로 둔다.
