# 다른 카메라 커스텀 펌웨어에서 가져올 만한 것 (2026-11-04)

Magic Lantern (캐논 5D/6D 계열), CHDK (캐논 컴팩트), OpenMemories (소니 PMCA 세대), Nikon Hacker, 그리고 metol (NX500) 의 기능을 훑고 우리 nx500ex 와 대조한 것. 코드는 보지 않았고 기능 이름과 설명, 공개 문서만 봤다. 구현은 우리 부품 (라이브 뷰 버퍼 읽기 nxmem/nxweb, X11 캡처와 그리기, GPIO 셔터 nxgpio, st key, prefman, capdtm, LUT 뱅크) 으로 어떻게 되는지를 적었다.

출처: Magic Lantern 저장소의 기능 플래그 (src/all_features.h) 와 모듈 README (reticulatedpines/magiclantern_simplified), 위키백과 Magic Lantern 항목, ma1co/OpenMemories-Tweak README, docodethatmatters.com 의 A6000/A6400 정리, Nikon Hacker 관련 기사 (petapixel, diyphotography), WApaperplane/metol 커밋 메시지와 릴리스 노트. CHDK 와 ML 위키는 접근이 막혀 (403/402) 기억에 의존한 부분은 그렇게 표시했다.

## 1. 다른 커펌의 구조와 우리 구조

| | Magic Lantern | CHDK | OpenMemories (소니) | 우리 (nx500ex) |
| --- | --- | --- | --- | --- |
| 올리는 방식 | 카드의 부트 플래그로 카드에서 자체 코드 실행, 펌웨어 무수정 | 카드 부팅 (SD 잠금 스위치) 로 자체 코드, 펌웨어 무수정 | PMCA 앱 설치 경로로 안드로이드 앱 실행, 설정 파일 (Backup.bin) 직접 편집 | 블루투스 래퍼 한 파일로 SD 의 스크립트 실행, 나머지는 전부 SD |
| 화면 | 카메라 UI 위에 자체 오버레이 (히스토그램, 제브라 등) 를 직접 그림 | 자체 OSD | 앱 화면 | X11 창 (nxmenu, nxpopup, blackout). 라이브 뷰는 NV12 버퍼로 읽음 |
| 키 | 카메라 키 이벤트 가로채기 (일부 키는 ML 이 먹음) | 자체 키 처리 | 앱 키 | evdev 감시 (nxkeys) + st key 주입 + GPIO 셔터 |
| 촬영 제어 | 카메라 내부 함수 호출 (셔터, 노출, 초점 모터, 센서 레지스터) | 내부 함수 | 설정값만 | st 명령, prefman, capdtm, GPIO 셔터, st cap iq af mv |

ML 과 CHDK 는 펌웨어 내부 함수를 직접 부르므로 센서 레지스터 (Dual ISO, crop 모드, FPS 오버라이드) 까지 손댄다. 우리는 카메라 앱 바깥에서 명령과 버퍼로만 다루므로 그런 종류는 안 되고, 그 대신 X11 과 버퍼로 "보여 주는 것" 과 셔터/키/설정으로 "시키는 것" 은 거의 다 된다.

## 4. 소니, 니콘 쪽에서 참고할 것

- OpenMemories-Tweak 는 설정 파일 (Backup.bin, 약 15,000 항목) 의 숨은 값을 바꾸는 방식이라 우리 prefman 과 같은 결이다. 30분 녹화 제한 해제, 언어, NTSC 경고, 텔넷/adb, WiFi 상시 연결 (절전 시작 시간을 늘려 자동 꺼짐 방지). 우리 쪽 대응: 녹화 제한은 상류 r-limit.sh (카탈로그), WiFi 상시 연결은 wifi.sh, 자동 꺼짐 해제는 로드맵 Mod Lapse 묶음.
- 소니 PMCA 앱 (지금은 아카이브): Time-lapse, Smart Remote, Touchless Shutter, Multiple Exposure, Star Trail, Sky HDR, Light Shaft, Digital Filter. 기능 개념은 A 표에 넣었다.
- Nikon Hacker (2012~2014): 녹화 시간 제한, 비트레이트, NEF 무손실, 타사 배터리 검사 끄기, 클린 HDMI. 영상 쪽은 다른 세션의 영상 후보와 겹치고, 배터리 검사는 NX 에 해당 없음.
- Magic Lantern 2025 (Midsummer Edition): 200D, 750D, 6D Mark II, 7D Mark II 지원 추가, 인터벌, 크롭 마크, 셔터 카운트, 30분 LV 제한 해제 같은 기본부터. 5D3 쪽은 3:2 오픈 게이트와 5.7K 아나모픽 RAW 영상 (센서 레지스터, 우리는 불가).

## 5. metol 근황 (10-25 ~ 11-02, 커밋 메시지와 릴리스만)

- 2.88.0-nxwa.12 (11-02): 두 LUT 를 각각 강도로 섞는 혼합 엔진 (브라우징 때 길게 눌러 A/B 표시, 혼합 상태에서는 두 강도만 조절), 두 라이브러리의 추가/삭제/정렬과 패널 편집 상태, 카메라의 실체 키 16 개를 전부 채집해 바인딩하고 다이얼을 연속 조절기로 씀, 길게 누르기를 편집 상태로 되돌리고 좌우 스와이프 삭제.
- 10-25: 라이카/핫셀블라드/소니 FL 서명색 5 장 추가 뒤 기준에 따라 87 -> 69 장으로 정리, FilmLab 레시피 파싱 수정.
- 11-02: 샤오홍수/더우인/레딧 홍보 문안, 빌드가 재현되지 않는다는 기록 (매번 6 바이트 차이).
- 우리와 겹치는 지점: LUT 강도와 두 LUT 혼합 (B 표), 다이얼 회전을 입력으로 (B 표 키 설정). 개념만 참고하고 구현은 우리 방식으로.

## 6. 추천 (가치 높고 우리 부품으로 되는 것부터)

1. 노출 보조 오버레이 묶음: 제브라, 히스토그램, 웨이브폼, 피킹, 크롭 마크. 한 X11 오버레이 프로그램 (nxosd) 에 모드로 넣고, 웹 원격에는 JS 로 같은 계산. 카운트다운 표시와 같은 부품에서 출발.
2. 인터벌 고도화: 노출 램핑 (홀리 그레일), 시작 지연/정지 조건, 장마다 노출 CSV, PC 디플리커 사이드카.
3. 자동 화면 끄기 (무입력 N 초).
4. 모션 감지 촬영 (번개, 터치리스 셔터 포함).
5. LUT 강도와 두 LUT 혼합 (카메라 안 C 보간).
6. 전자 수평계 (가속도계 sysfs 확인 뒤).
7. 고스트 이미지 (다중 노출 대안과 같이).
8. 랙 포커스, 벌브 ND 계산, 스타 트레일 PC 합성은 쓸 때 되면.
