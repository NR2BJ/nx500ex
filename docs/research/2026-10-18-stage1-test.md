## 2026-10-18

| 항목 | 결과 |
| --- | --- |

| 제거 | 확인 필요 |

## 알게 된 것

- dfmsd 는 nx_cs.adj 의 shell script 경로가 약 32자를 넘으면 실행하지 않는다. 31자는 동작, 34자는 실패. 커뮤니티 패키지는 모두 28자 이하를 썼다.
- 블루투스 서비스 시작부터 keyscan 의 auto 스크립트 실행까지 약 1초. 지연의 대부분은 카메라가 블루투스를 시작하기까지의 시간이다.

- 켤 때마다 블루투스가 다시 시작되므로 SD 의 keyscan 도 매번 다시 올라온다. keyscan 을 내장에 둘 필요가 없다 (2절 가정 확정).
- 블루투스 OFF 때의 동작은 "끌 때 프로세스를 죽이지 않고 얼린다(freezer cgroup), 그리고 부팅 때 시작된 블루투스와 설정 화면에서 시작된 블루투스는 관리 방식이 다르다"는 가설로 모두 설명된다. 다시 ON 했을 때 AF 광이 없었던 것은 얼었던 keyscan 이 풀려나 동작하고, 새 keyscan 은 "이미 실행 중"이라 시작하지 않았기 때문으로 본다.
- 가설 확인용으로 boot.sh 와 EV_S1.sh 가 cgroup 과 프로세스 상태를 log/boot.log 에 남기도록 수정했다.
