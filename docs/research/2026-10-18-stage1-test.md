## 알게 된 것

- dfmsd 는 nx_cs.adj 의 shell script 경로가 약 32자를 넘으면 실행하지 않는다. 31자는 동작, 34자는 실패. 커뮤니티 패키지는 모두 28자 이하를 썼다.
- 블루투스 서비스 시작부터 keyscan 의 auto 스크립트 실행까지 약 1초. 지연의 대부분은 카메라가 블루투스를 시작하기까지의 시간이다.

- 켤 때마다 블루투스가 다시 시작되므로 SD 의 keyscan 도 매번 다시 올라온다. keyscan 을 내장에 둘 필요가 없다 (2절 가정 확정).
- 두 번째 측정(18:03~18:05) 로그: boot.sh 는 cgroup systemd:/system.slice/dbus.service 안에서 실행되고 freezer 는 최상위(/)다. bluetoothd 가 D-Bus 로 시작되기 때문이다. 블루투스 서비스에 묶이거나 얼려지지 않으므로 "블루투스 OFF 시 freezer 로 정지" 가설은 철회.
- 두 번째 측정에서는 설정에서 켠 블루투스를 다시 꺼도 조합키가 동작했다 (18:04:40, 18:04:51). 첫 측정에서 조합키가 멈췄던 현상은 재현되지 않았고 원인 미상.
- 18:04:56 의 boot.sh 는 keyscan 시작 여부 기록 전에 끝났다 (직후 전원을 끈 것으로 추정).
- EV_S1.sh 의 진단은 pidof 가 없어 실패했다. /proc 을 직접 읽도록 수정했다.
- 결론: 켤 때 블루투스가 켜져 있으면 모드가 올라온다는 것만 보장한다. 블루투스 OFF 시 동작은 보장하지 않는다. 기능별 켜기/끄기는 메뉴 체크박스로 한다.

## 원인 조사 준비 (2026-10-18)

- 첫 측정 로그 17:54:45~17:54:56 재해석: 블루투스를 다시 켰을 때 boot.sh 는 실행됐지만 00_hello 가 돌지 않았다. 새 keyscan 이 "이미 실행 중"이라 종료했다고 보면, 블루투스를 꺼 둔 동안에도 기존 keyscan 은 살아 있었고 반응만 없었던 것이다.
- 남은 질문: 살아 있는 keyscan 이 왜 반응하지 않았나. 키를 못 받았는지, 받고도 스크립트를 실행하지 못했는지, 정지(T) 상태였는지.
- 진단판 boot.sh, bin/mon.sh, keyscan debug 출력으로 구분한다. 절차는 sd/stage1-test/README.md.

## 원인 조사 결과 (2026-10-18 18:13~18:16)

단계별 결과 (1 동작, 2 안 됨): 1 1 1 . 2 1 1 1 1. 6단계에서 블루투스를 켤 때 AF 광 1초, 7단계는 끈 직후와 10초 뒤 모두 동작.

- 동작 규칙: 전원을 켤 때 블루투스가 켜져 있으면 모드가 올라온다. 꺼져 있었으면 블루투스를 켜는 순간 올라온다. 한 번 올라온 모드는 블루투스를 끄고 켜도 계속 동작한다.
- (정정됨, 아래 세 번째 측정 참고) 당시에는 "두 번째로 켤 때 boot.sh 가 실행되지 않는다"고 보았으나, 기록 유실 때문에 그렇게 보였을 뿐이다.
- 첫 테스트에서 블루투스 OFF 직후 조합키가 멈췄던 현상은 이후 세 번 시도에서 재현되지 않았다. 일시적 현상으로 보고 조사를 종료한다.
- 기록 문제: mon.log, keyscan.out 이 0바이트였고 boot.log 에서 1~3단계 EV_S1 기록이 빠졌다. 스크립트가 sync 없이 써서 메모리에만 있던 내용이 전원 OFF 와 카드 분리 때 사라진 것으로 본다. keyscan 의 debug 출력은 stdio 버퍼(4KB) 때문에 늦게 나온다. 모든 기록 뒤에 sync, 감시 기록은 덮어쓰기 대신 덧붙이기로 수정했다.
- 앞으로 SD 에 쓰는 모든 스크립트는 쓰기 뒤에 sync 를 한다 (설계 원칙에 추가).

추가 관찰

- 18:13:16 auto/00_hello.sh 의 SD 쓰기에서 Input/output error. 전원 ON 직후 SD 가 쓰기 가능 상태가 아니었던 것으로 보인다. 두 번째 측정의 기록 유실 원인 중 하나일 수 있다. 실제 기능 스크립트는 켠 직후 SD 쓰기 실패 시 재시도한다.

결론: 모드는 전원 ON 또는 블루투스 ON 때 시작되고, 전원 OFF 때까지 블루투스 상태와 무관하게 동작한다. 단계 1 경로 검증 완료 (제거 확인만 남음).
