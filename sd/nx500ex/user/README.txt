여기에 내 스크립트를 넣는다.
  button.sh        메뉴의 "사용자 버튼" 을 누르면 실행 (들어 있는 것은 AF 보조광을 1초 켜는 예시)
  checkbox.sh      메뉴의 "사용자 체크박스" 를 켜면 실행 (처음에는 없음. 만들기 전에는 체크해도 아무 일도 없다), 켜 둔 동안 전원/블루투스를 켤 때마다 실행
  off_checkbox.sh  "사용자 체크박스" 를 끌 때 실행
키 조합을 추가하려면 nx500ex/scripts 에 EV_키이름.sh 를 만든다 (예: EV_OK.sh, EV_AEL.sh, MOBILE_MOBILE.sh).
