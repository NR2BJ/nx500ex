# nx500ex SD 패키지 (단계 2 첫 판)

이 폴더를 SD 카드 루트에 nx500ex 라는 이름 그대로 복사한다. 내장에는 stage1-install 로 래퍼(v2)가 설치되어 있어야 하고, 카메라 설정에서 블루투스를 켜 둔다.

## 동작 규칙

| 상황 | 동작 |
| --- | --- |
| 블루투스 켜짐 (전원 ON 포함) | 모드 시작. 켜 둔 기능(체크박스)을 다시 적용 |
| 블루투스 끔 | 2초 안에 모드 정지. 켜 둔 기능은 순정 상태로 되돌림 (체크 상태는 유지되어 다시 켜면 재적용) |
| 전원 OFF | 모드 정지 |
| nx500ex/DISABLE 파일 있음 | 아무것도 실행하지 않음 |
| nx500ex 폴더 없음 | 순정과 같음 |

## 키 조합

| 키 | 동작 |
| --- | --- |
| EV 두 번 | 메뉴 열기 / 닫기. 촬영 작업 중에는 작업 중단 |
| EV + 왼쪽 | AF-S/단사 와 AF-C/고속연사 전환 |
| EV + 오른쪽 | 터치스크린 켜기/끄기 |
| EV + 위 / 아래 | UP / DN 프로필 불러오기 |
| EV + WiFi | 텔넷/FTP 상태와 IP 보기 (켜고 끄기는 메뉴 체크박스) |
| 비어 있음 | EV + 반셔터, EV + AEL, WiFi 두 번 등. scripts 에 EV_AEL.sh 처럼 만들면 된다 |

EV 는 다른 키보다 먼저 누르고 있어야 한다.

## 메뉴

메뉴 프로그램은 bin/nxmenu 다 (tools/nxmenu 에서 빌드, NX-KS mod_gui 를 바탕으로 새로 작성). 모든 화면이 2열 x 5행 같은 칸 크기이고, 마지막 행은 왼쪽 뒤로, 오른쪽 닫기로 고정이다. 메뉴는 화면 가운데에 뜨고 위아래로 카메라 정보가 조금씩 보인다 (화면 전체를 덮으면 카메라 앱이 멈추며 Xorg 가 죽었다). EV 두 번은 마지막으로 보던 화면을 연다 (이번 전원 동안).

| 화면 | 항목 |
| --- | --- |
| 첫 화면 | 무음 셔터, 렌즈 없이 촬영, 촬영 도구 >, 프로필 >, 설정 > |
| 촬영 도구 | 셀프타이머 >, 벌브 >, 인터벌 촬영 >, HDR 5장 >, 포커스 스태킹 >, 작업 중단, 작업 중 화면 끄기 |
| 셀프타이머 | 셀프타이머 시작, 시간 (2~60초), 타이머 램프 |
| 벌브 | 벌브 시작, 노출 (1~3600초) |
| 인터벌 촬영 | 인터벌 시작, 간격 (2~3600초), 장수 (0 = 중단할 때까지) |
| HDR 5장 | HDR 시작, 간격 (1~3 EV) |
| 포커스 스태킹 | 가까운 끝 저장, 먼 끝 저장, 스태킹 시작, 장수, 작업 중단 |
| 프로필 | UP/DOWN 저장, 불러오기, 전체 백업, 전체 복원 (복원 뒤 전원 꺼짐) |
| 설정 | 텔넷 / FTP, IP, 셔터 횟수, 진단 기록 |

숫자 항목은 "이름: 값" 으로 보이고, 누르면 메뉴 안의 숫자 화면이 뜬다 (키패드 없음, 바로 뜸). 값은 conf 폴더에 저장된다.

| 항목 | 단계 |
| --- | --- |
| 셀프타이머 시간 | ±1, ±5, ±10 초 |
| 벌브 노출, 인터벌 간격 | ±1, ±10, ±60 초 |
| 인터벌 장수 | ±1, ±5, ±10, "계속" 버튼 (0 = 중단할 때까지) |
| HDR 간격 | ±1 EV (1~3) |
| 스태킹 장수 | ±1, ±5, ±10 |

누른 뒤 동작: 체크박스, 화면 이동, 숫자 설정은 메뉴가 그대로 있다. 촬영 시작, 셔터 횟수, 프로필은 메뉴가 닫힌다 (화면을 가리지 않게).

| 항목 | 내용 |
| --- | --- |
| 무음 셔터 | 완전 전자셔터. 순정 단사와 이 메뉴의 촬영 작업(단사로 바꿔 찍음)에서 적용. 순정 연사는 기계 셔터, 순정 노출 브라케팅은 한 장만 찍힌다 (펌웨어 동작이라 고치려면 내장 수정이 필요해 하지 않음). 무음 브라케팅은 HDR 5장을 쓴다. 어두운 부분 잡음이 기계 셔터보다 약 37% 많다 (ISO 3200 다크 프레임 실측) |
| 렌즈 없이 촬영 | 렌즈 미인식 상태에서도 셔터 허용. "렌즈 분리됨" 안내는 반셔터를 누르면 사라지고 촬영된다. 조리개는 -- |
| 셀프타이머 | 지금 드라이브 모드(브라케팅, 연사) 그대로 촬영 |
| 벌브 (장노출) | M 모드에서 사용. 30초 이하는 셔터 속도를 그 시간(가장 가까운 표준값, 예 7초 -> 6초)으로 맞춰 보통 단사로 찍고 되돌린다 (무음 셔터와 함께 쓸 수 있는지는 확인 중). 30초 초과는 BULB 로 찍고 끝낼 때 캡처 중지 명령을 보낸다 (시험 중). 사진이 안 생기면(초점 실패) 알린다 |
| 인터벌 촬영 | 반셔터를 누른 채 두고 셔터만 누른다. 첫 장에서 잡힌 초점(P/A/S 면 노출도)으로 끝까지 찍는다. 첫 장이 초점 실패로 안 찍히면 중단. 촬영이 밀리면 몰아서 찍지 않고 그때부터 다시 간격을 센다 |
| HDR 5장 | M 모드에서 가운데 노출을 맞춘 뒤 시작. 셔터 속도만 바꿔 다섯 장 (30초 ~ 1/6000 범위). 셔터 값을 바꿀 때 반셔터가 풀려 장마다 초점을 다시 잡으므로, AF 면 모든 장에서 초점이 맞아야 한다 (안 맞는 장에서 중단). 삼각대와 MF 를 권장. 끝나면 셔터 복원 |
| 포커스 스태킹 | AF 렌즈만. 반셔터를 누른 채 초점 모터를 직접 움직이므로 화면의 거리 표시는 따라오지 않는다 (사진은 맞게 찍힘) |
| 작업 중 화면 끄기 | 벌브, 인터벌, HDR 동안 화면 전체를 검은 창으로 덮는다 (AMOLED 라 꺼진 것과 같음). 팝업은 그 위에 뜬다 |
| 텔넷 / FTP | 서버를 켜 둔다 (전원 켤 때마다 자동). WiFi 연결 전에도 서버는 떠 있고 연결되면 접속 가능. IP 는 IP 항목이나 EV+WiFi. 인증 없음, 본인 기기만 있는 네트워크에서만 |
| 셔터 횟수 | 셔터, 전원, 플래시 횟수. 전원을 끌 때 저장되는 값이라 켜져 있는 동안 찍은 수는 다음 전원 켜기부터 반영 |
| 진단 기록 | 다음 블루투스 켜기부터 log/mon.log, log/keyscan.out, 바로 다음 동작부터 log/timing.log |

촬영 작업(벌브, 인터벌, HDR, 스태킹)은 한 번에 하나만 돈다. 도는 동안 드라이브를 단사로 바꿨다가 끝나면 되돌린다 (연사 상태면 셔터를 누를 때마다 여러 장이 찍히고 무음 셔터도 적용되지 않았다). 도는 동안 EV 두 번은 메뉴 대신 작업 중단이다 (화면을 꺼 둔 상태에서도 중단할 수 있게). 블루투스를 꺼도 중단된다. 기록은 log/jobs.log, 입력한 값은 conf 폴더에 남아 다음에 기본값이 된다.

체크박스를 켜면 그 스크립트가 scripts/auto 에 복사되어 전원(블루투스)을 켤 때마다 자동 적용된다. 체크박스마다 따로 기억되므로, 무음 셔터를 켜 두면 끌 때까지 다음 전원 켜기에도 켜진 상태다. PC 에서 scripts/auto 를 보면 무엇이 켜져 있는지 알 수 있다.

## 폴더 구조

```
nx500ex/
  boot.sh              내장 래퍼가 부름
  bin/                 keyscan, nxmenu, popup_*, poker, stapp, blackout, busybox, telnetd, watch.sh, mon.sh
  scripts/             키 조합(EV_*.sh), 기능, 메뉴(gui_*.NX500), common.sh
  scripts/auto/        켜 둔 기능 (체크박스가 관리)
  presets/             프로필과 전체 백업 (처음 저장할 때 생김)
  log/                 boot.log 등
```

## 첫 확인 순서

1. SD 의 기존 nx500ex 폴더(검증용)를 지우고 이 폴더를 복사한다.
2. 블루투스 켠 채로 전원 ON. 몇 초 뒤 EV 두 번으로 메뉴가 뜨는지, 한글이 깨지지 않는지 본다.
3. 메뉴의 각 항목을 한 번씩 눌러 본다. 무음 셔터를 체크하고 촬영해 셔터 소리가 없는지 확인한다.
4. 블루투스를 끄고 촬영해 셔터 소리가 돌아왔는지, 다시 켜고 무음이 되는지 확인한다.
5. 키 조합을 하나씩 확인한다.
6. 이상하면 메뉴에서 진단 기록을 켜고, 블루투스를 껐다 켠 뒤 다시 해 보고 log 폴더를 전달한다.

## 텔넷, FTP 접속

브라우저로는 접속되지 않는다 (웹 서버가 아님).

| 용도 | 방법 |
| --- | --- |
| 텔넷 | PuTTY 등 텔넷 프로그램. 연결 종류 Telnet, 주소 카메라 IP, 포트 23. 사용자 root, 비밀번호 없음 |
| FTP | 윈도우 탐색기 주소창에 ftp://카메라IP, 또는 FileZilla. SD 카드 내용이 보인다 |

카메라가 WiFi 기능 화면을 나오면 연결을 끊을 수 있다. 접속이 안 되면 WiFi 화면에 머문 채로 시도해 본다.

## 키 할당 바꾸기

지금 keyscan 이 인식하는 것은 EV 를 누른 채 다른 키를 누르는 순간, 같은 키 1초 안에 두 번, 모드 다이얼이 SAS 를 떠나는 순간뿐이다. 길게 누르기, 누르는 동안, 떼는 순간은 단계 3 의 keyscan2 에서 추가한다.

scripts 폴더의 파일 이름이 곧 키 할당이다. EV_<키>.sh (EV 를 누른 채 그 키), <키>_<키>.sh (같은 키 두 번) 형식이다.
키 이름: OK, AEL, UP, DOWN, LEFT, RIGHT, S1(반셔터), S2(셔터), MOBILE(WiFi), FN, DEL, PB(재생), EV.
예: 메뉴의 셀프타이머를 EV+반셔터에 걸려면 scripts 에 EV_S1.sh 를 만들고 내용을 sh "$NX500EX/scripts/timer.sh" 한 줄로 한다.
