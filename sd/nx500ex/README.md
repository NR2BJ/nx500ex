# nx500ex SD 패키지 (단계 2 첫 판)

이 폴더를 SD 카드 루트에 nx500ex 라는 이름 그대로 복사한다. 내장에는 stage1-install 로 래퍼(v2)가 설치되어 있어야 하고, 카메라 설정에서 블루투스를 켜 둔다.

## 동작 규칙

| 상황 | 동작 |
| --- | --- |
| 블루투스 켜짐 (전원 ON 포함) | 모드 시작. 켜 둔 기능(체크박스)을 다시 적용 |
| 블루투스 끔 | 2초 안에 모드 정지. 켜 둔 기능은 순정 상태로 되돌림 (체크 상태는 유지되어 다시 켜면 재적용) |
| 전원 OFF | 모드 정지 |
| nx500ex/DISABLE 파일 있음 | 아무것도 실행하지 않음 |
| nx500ex 폴더 없음 | 순정과 같음 |

## 키 조합

EV 두 번만 고정이다: 메뉴 열기 / 닫기, 촬영 작업 중에는 작업 중단. 나머지 키는 메뉴의 설정 > 키 설정에서 정한다 (처음에는 모두 비어 있다).

| 키 설정 화면 | 고를 수 있는 키 |
| --- | --- |
| EV 조합 | EV 를 누른 채 OK, AEL, 위, 아래, 왼쪽, 오른쪽, 반셔터, WiFi, Fn, 삭제, 재생 |
| 두 번 누르기 | 1초 안에 두 번: OK, AEL, 위, 아래, 왼쪽, 오른쪽, WiFi, Fn, 삭제, 재생 |
| 길게 누르기 | 0.8초 이상: OK, AEL, 위, 아래, 왼쪽, 오른쪽, WiFi, Fn, 삭제, 재생, EV |

키를 누르면 동작 목록(scripts/actions.list)이 뜨고, 고른 결과는 conf/keymap 에 저장되어 바로 적용된다. "없음" 을 고르면 지운다. 카메라 자체의 키 동작은 막을 수 없으므로(예: OK 길게에 할당해도 OK 본래 동작은 일어난다) 카메라가 그 키로 하는 일과 겹치지 않는 조합을 고른다.

## 메뉴

메뉴 프로그램은 bin/nxmenu 다 (tools/nxmenu 에서 빌드, NX-KS mod_gui 를 바탕으로 새로 작성). 모든 화면이 2열 x 5행 같은 칸 크기이고, 마지막 행은 왼쪽 뒤로, 오른쪽 닫기로 고정이다. 메뉴는 화면 가운데에 뜨고 위아래로 카메라 정보가 조금씩 보인다 (화면 전체를 덮으면 카메라 앱이 멈추며 Xorg 가 죽었다). EV 두 번은 마지막으로 보던 화면을 연다 (이번 전원 동안).

| 화면 | 항목 |
| --- | --- |
| 첫 화면 | 무음 셔터, 렌즈 없이 촬영, 촬영 도구 >, 필름 레시피 >, LUT >, 프로필 >, 설정 > |
| 필름 레시피 | 컬러 네거티브 >, 슬라이드 >, 흑백 >, 영화 >, 즉석, 스타일 > (43개), 레시피 끄기, 화이트 밸런스 유지, 촬영 도구 > (비교 촬영 목록, 비교 촬영 전체, 보정 촬영, LUT 검증 촬영) |
| 촬영 도구 | 셀프타이머 >, 벌브 >, 인터벌 촬영 >, HDR 5장 >, 포커스 스태킹 >, 작업 중단, 작업 중 화면 끄기, 재생 화면 묶기 |
| LUT | 기본 > (자체 룩 11), 코닥 > (19), 후지 > (22), 아그파 일포드 롤라이 > (19, 로모 포함), 폴라로이드 즉석 > (12), 스타일 > (23), 영화 인화 > (4), LUT 끄기. 회사별 표는 공개 필름 에뮬레이션 모음 (lut/LICENSE-haldclut.txt, CC BY-SA 4.0) 을 변환한 것 |
| 셀프타이머 | 셀프타이머 시작, 시간 (2~60초), 타이머 램프 |
| 벌브 (장노출) | 장노출 시작, 노출 (1~30초) |
| 인터벌 촬영 | 인터벌 시작, 간격 (2~3600초), 장수 (0 = 중단할 때까지) |
| HDR 5장 | HDR 시작, 간격 (1~3 EV) |
| 포커스 스태킹 | 가까운 끝 저장, 먼 끝 저장, 스태킹 시작, 장수, 작업 중단 |
| 프로필 | UP/DOWN 저장, 불러오기, 전체 백업, 전체 복원 (복원 뒤 전원 꺼짐) |
| 설정 | 텔넷 / FTP, IP, 셔터 횟수, 진단 기록, 키 설정 > |

숫자 항목은 "이름: 값" 으로 보이고, 누르면 메뉴 안의 숫자 화면이 뜬다 (키패드 없음, 바로 뜸). 값은 conf 폴더에 저장된다.

| 항목 | 단계 |
| --- | --- |
| 셀프타이머 시간 | ±1, ±5, ±10 초 |
| 장노출 | ±1, ±5, ±10 초 |
| 인터벌 간격 | ±1, ±10, ±60 초 |
| 인터벌 장수 | ±1, ±5, ±10, "계속" 버튼 (0 = 중단할 때까지) |
| HDR 간격 | ±1 EV (1~3) |
| 스태킹 장수 | ±1, ±5, ±10 |

누른 뒤 동작: 체크박스, 화면 이동, 숫자 설정은 메뉴가 그대로 있다. 촬영 시작, 셔터 횟수, 프로필은 메뉴가 닫힌다 (화면을 가리지 않게).

| 항목 | 내용 |
| --- | --- |
| 무음 셔터 | 완전 전자셔터. 실제 노출은 약 0.2초에서 멈춘다 (1/5 까지 정확, 그보다 느리면 모두 약 0.2초, 수 초 이상은 사진이 깨짐. 실측). 촬영 작업은 1/5 보다 느리면 거부. 순정 단사와 이 메뉴의 촬영 작업(단사로 바꿔 찍음)에서 적용. 순정 연사는 기계 셔터, 순정 노출 브라케팅은 한 장만 찍힌다 (펌웨어 동작이라 고치려면 내장 수정이 필요해 하지 않음). 무음 브라케팅은 HDR 5장을 쓴다. 어두운 부분 잡음이 기계 셔터보다 약 37% 많다 (ISO 3200 다크 프레임 실측) |
| 렌즈 없이 촬영 | 렌즈 미인식 상태에서도 셔터 허용. "렌즈 분리됨" 안내는 반셔터를 누르면 사라지고 촬영된다. 조리개는 -- |
| 셀프타이머 | 지금 드라이브 모드(브라케팅, 연사) 그대로 촬영 |
| 벌브 (장노출) | M 모드에서 사용. 셔터 속도를 정한 시간(그 이하에서 가장 긴 표준값, 예 7초 -> 6초, 최대 30초)으로 맞춰 보통 단사로 찍고 되돌린다. 카메라의 BULB 는 스크립트로 끝낼 수 없어(30초에 끝남) 쓰지 않는다. 무음 셔터가 켜져 있으면 거부. 사진이 안 생기면(초점 실패) 알린다 |
| 인터벌 촬영 | 반셔터를 누른 채 두고 셔터만 누른다. 첫 장에서 잡힌 초점(P/A/S 면 노출도)으로 끝까지 찍는다. 첫 장이 초점 실패로 안 찍히면 중단. 촬영이 밀리면 몰아서 찍지 않고 그때부터 다시 간격을 센다 |
| HDR 5장 | M 모드, ISO 고정(자동이면 거부)에서 가운데 노출을 맞춘 뒤 시작. 무음 셔터면 가장 긴 장이 1/5초보다 느릴 때 거부. 셔터 속도만 바꿔 다섯 장 (30초 ~ 1/6000 범위). 셔터 값을 바꿀 때 반셔터가 풀려 장마다 초점을 다시 잡으므로, AF 면 모든 장에서 초점이 맞아야 한다 (안 맞는 장에서 중단). 삼각대와 MF 를 권장. 끝나면 셔터 복원 |
| 포커스 스태킹 | AF 렌즈만. 초점 모터를 직접 움직이고, 촬영 서비스의 MF(st cap capt mf on)를 켜서 셔터 때 초점을 다시 잡지 않게 한다 (기계, 무음 모두 확인). 화면의 거리 표시는 한 장씩 늦게 따라온다. 장마다 촬영 전후 초점 위치를 jobs.log 에 남긴다 |
| 작업 중 화면 끄기 | 벌브, 인터벌, HDR 동안 화면 전체를 검은 창으로 덮는다 (AMOLED 라 꺼진 것과 같음). 팝업은 그 위에 뜬다 |
| 재생 화면 묶기 | 인터벌, HDR, 포커스 스태킹으로 찍은 사진을 순정 연사처럼 재생 화면에서 한 묶음으로 보이게 한다. 작업이 끝나면(중단 포함) 새로 생긴 JPG, SRW 의 메이커노트에 순정 연사와 같은 묶음 정보(태그 0x000a)를 bin/nxgroup 으로 넣는다. 파일 크기와 사진 데이터는 그대로이고 메이커노트 목록 안의 빈 항목 두 개를 쓴다 (SRW 는 값 없는 항목, JPEG 는 얼굴 인식 항목 0x00e0 과 FaceDetect(끔)). 얼굴 인식을 켜고 찍은 JPEG 는 건드리지 않을 수 있다. 끝난 뒤 저장이 멈출 때까지 2초 이상 기다렸다가 고친다. 카메라는 재생 목록을 전원을 켤 때만 카드에서 다시 읽어서, 묶음은 다음 전원 켜기부터 보인다 (순정 연사는 바로). 기본은 꺼짐 |
| 필름 레시피 | P, A, S, M 모드에서 사용. 레시피 값(R, G, B 게인, 색조, 채도, 선명도, 대비)을 화면 마법사 사용자 1 에, WB(필름의 밸런스대로: 주광용 5500K, 텅스텐 필름 3200K, 흑백과 스타일도 5500K)를 prefman 으로 쓰고, 촬영 모드를 다시 들어가 카메라 앱이 다시 읽게 한다 (Fn 패널 없이 1~2초). 반영된 값을 읽어 확인하고 팝업으로 알린다. 처음 바꿀 때 사용자 1 의 원래 값(conf/pw_custom1.bak)과 원래 화면 마법사 종류, WB(conf/film_orig.bak)를 남긴다. 레시피 끄기는 사용자 1 의 값, 화면 마법사 종류, WB 를 모두 레시피 전으로 되돌린다. "화이트 밸런스 유지" 를 켜면 WB 는 건드리지 않는다. 레시피는 scripts/film/recipes.txt (실제 필름 특성 조사로 정한 값, docs/research/2026-10-19-film-stock-profiles.md), 메뉴는 tools/film/gen_pages.py 로 만든다. 레시피에 LUT 칸(12번째)이 있으면 3D LUT 도 같이 쓴다 (2026-10-25): 화면 마법사가 WB, 선명도, 큰 대비와 채도를 맡고 LUT 는 화면 마법사로 못 내는 색의 모양 (세피아, 셀레늄 토닝, Metropolis 의 색별 채도, Polaroid 600 과 SX-70 의 스플릿 토닝, Pro 160NS 의 후지 녹색, 크로스 프로세스의 섀도 색, 바랜 인화의 들뜬 블랙) 만 맡는다. 레시피를 바꾸면 LUT 도 같이 바뀌고 레시피 끄기는 LUT 도 끈다. 메뉴 LUT 에서 직접 고른 것은 레시피가 건드리지 않는다 |
| LUT (3D 색 표) | 카메라 이미지 처리 메모리의 3D LUT 표 42개 (0x810c3500 부터, 17x17x17, 항목 (Cr, Cb, Y, 0) 8비트) 를 전부 우리 표로 바꾼다 (bin/nxmem, scripts/lut.sh). 라이브 뷰는 화면 마법사 표준에서 표 17 을 쓰지만 정지 사진은 밝기, 색온도에 따라 다른 표를 고르므로 42개 모두 바꾼다 (표 17 만 바꾸면 화면은 바뀌고 사진은 그대로인 경우가 있었다, 2026-10-25 실기). 표 파일은 lut/<id>_a.bin (구간 A, 표 20개) 과 lut/<id>_b.bin (구간 B, 표 22개), 목록은 lut/luts.txt, 만드는 도구는 tools/lut/make_luts.py (tools/lut/looks.py 의 룩 함수를 tools/lut/cube2bank.py 로 변환, 표마다 카메라 원래 표를 먼저 거쳐 순정의 상황별 처리와 밝은 곳 채도 억제를 유지. _a, _b 파일은 커서 저장소에 없고 이 도구로 만든다). 타사 .cube 는 tools/lut/add_cube.py <id> "<메뉴 이름>" 파일.cube 로 더한다 (뱅크 생성, 목록 추가, 메뉴 재생성). 격자 노드는 입력 i x 16 (순정 항등 표의 모양으로 확인), 변환은 BT.601 전범위 (LUT 검증 촬영으로 확정). 처음 바꿀 때 원래 표를 conf/lut_orig_a.bin, lut_orig_b.bin 에 남기고, 쓴 뒤 반셔터 키를 넣어 다시 적재시킨다 (적재는 반셔터 때, 키 주입으로 됨). 켜 두면 scripts/auto/lut_reapply.sh 가 전원을 켤 때마다 다시 쓰고, 블루투스를 끄면 원래 표로 되돌린다. 표는 RAM 에만 있어 전원을 끄면 순정이다. LUT 는 화면 마법사(필름 레시피) 뒤 마지막 단계라 흑백 계열 LUT 를 켜면 레시피 색은 보이지 않는다. 근거는 docs/research/2026-10-25-lut-dump-analysis.md |
| LUT 검증 촬영 | M 모드, MF, JPEG 에서. 모니터의 색표를 lut/cal.txt 의 검증 표 8장(항등, 색상 +30도, 채도 1.6, 채도 0.5, R 감마 0.7, G 감마 1.3, B 감마 1.5, 전체 감마 0.75. 순정 표 합성 없는 순수 룩)으로 한 장씩 찍고 쓰던 LUT 로 되돌린다 (scripts/lutcal.sh, log/jobs.log 에 "lutcal <id> -> <파일>"). 흰 칸이 Y 200 을 넘지 않게 노출을 조금 어둡게. PC 의 tools/lut/lut_verify.py 가 항등 사진에서 각 룩의 결과를 BT.601/709, 전범위/제한 범위 네 모델로 예측해 실제와 ΔE 로 비교하고 카메라의 변환 모델을 고른다. 타사 .cube 가 의도대로 나오는지를 이것으로 보증한다 |
| 보정 촬영 (색표) | M 모드, MF, JPEG 에서. 모니터에 tools/film/calib_chart.png (컬러체커 24색) 을 띄우고 찍는다. 화면 마법사 값 하나씩만 바꾼 16장 (기준, 채도 5/15, 대비 5/15, R 90/110, G 110, B 90/110, 색조 8/12, 흑백 기준과 R 120/80, B 120) 을 자동으로 찍고 원래대로 되돌린다. WB 는 그동안 5500K. 장마다 값과 파일 이름을 log/jobs.log 에 남긴다. 결과를 PC 에서 재어 레시피 값의 기준을 잡는다 |
| 비교 촬영 (목록, 전체) | M 모드, MF, JPEG 에서. 같은 장면을 기준(중립, 5500K) 한 장과 레시피마다 한 장씩 자동으로 찍고 원래대로 되돌린다. 목록은 scripts/film/compare.txt (한 줄에 레시피 이름 하나), 전체는 41개 모두 (42장, 약 4분). 색표를 찍으면 PC 에서 tools/film/recipe_analyze.py 가 레시피마다 회색 기울기(밝은 쪽, 중간, 어두운 쪽), 색 계열별 채도, 피부, 하늘, 잎의 색상 변화, 대비, 날아간 칸을 재고 색 줄표(swatches.png)를 만든다. 실제 장면을 찍으면 --scene 으로 사진을 나란히 놓은 비교 시트(sheet.jpg)만 만든다 |
| 텔넷 / FTP | 서버를 켜 둔다 (전원 켤 때마다 자동). WiFi 연결 전에도 서버는 떠 있고 연결되면 접속 가능. IP 는 IP 항목이나 EV+WiFi. 인증 없음, 본인 기기만 있는 네트워크에서만 |
| 셔터 횟수 | 셔터, 전원, 플래시 횟수. 전원을 끌 때 저장되는 값이라 켜져 있는 동안 찍은 수는 다음 전원 켜기부터 반영 |
| 진단 기록 | 다음 블루투스 켜기부터 log/mon.log, log/keyscan.out, 바로 다음 동작부터 log/timing.log |

촬영 작업(벌브, 인터벌, HDR, 스태킹)은 한 번에 하나만 돈다. 도는 동안 드라이브를 단사로 바꿨다가 끝나면 되돌린다 (연사 상태면 셔터를 누를 때마다 여러 장이 찍히고 무음 셔터도 적용되지 않았다). 도는 동안 EV 두 번은 메뉴 대신 작업 중단이다 (화면을 꺼 둔 상태에서도 중단할 수 있게). 블루투스를 꺼도 중단된다. 기록은 log/jobs.log, 입력한 값은 conf 폴더에 남아 다음에 기본값이 된다.

체크박스를 켜면 그 스크립트가 scripts/auto 에 복사되어 전원(블루투스)을 켤 때마다 자동 적용된다. 체크박스마다 따로 기억되므로, 무음 셔터를 켜 두면 끌 때까지 다음 전원 켜기에도 켜진 상태다. PC 에서 scripts/auto 를 보면 무엇이 켜져 있는지 알 수 있다.

## 폴더 구조

```
nx500ex/
  boot.sh              내장 래퍼가 부름
  bin/                 nxkeys, nxmenu, nxpopup, nxgroup, nxmem, popup_*, poker, stapp, blackout, busybox, telnetd, watch.sh, mon.sh
  scripts/             키 조합(EV_*.sh), 기능, 메뉴(gui_*.NX500), common.sh
  scripts/auto/        켜 둔 기능 (체크박스가 관리)
  lut/                 3D LUT 표 (<id>_a.bin, <id>_b.bin 을 lut.sh 가 쓴다), luts.txt 목록 (id|이름|설명|분류), cal.txt 검증 순서, LICENSE-haldclut.txt (회사별 표의 출처와 라이선스), <id>.bin (표 17 자리 하나, 참고용)
  conf/                설정 값, 원래 값 백업 (lut_orig_a.bin, lut_orig_b.bin 등)
  presets/             프로필과 전체 백업 (처음 저장할 때 생김)
  log/                 boot.log 등
```

## 첫 확인 순서

1. SD 의 기존 nx500ex 폴더(검증용)를 지우고 이 폴더를 복사한다.
2. 블루투스 켠 채로 전원 ON. 몇 초 뒤 EV 두 번으로 메뉴가 뜨는지, 한글이 깨지지 않는지 본다.
3. 메뉴의 각 항목을 한 번씩 눌러 본다. 무음 셔터를 체크하고 촬영해 셔터 소리가 없는지 확인한다.
4. 블루투스를 끄고 촬영해 셔터 소리가 돌아왔는지, 다시 켜고 무음이 되는지 확인한다.
5. 키 조합을 하나씩 확인한다.
6. 이상하면 메뉴에서 진단 기록을 켜고, 블루투스를 껐다 켠 뒤 다시 해 보고 log 폴더를 전달한다.

## 텔넷, FTP 접속

브라우저로는 접속되지 않는다 (웹 서버가 아님).

| 용도 | 방법 |
| --- | --- |
| 텔넷 | PuTTY 등 텔넷 프로그램. 연결 종류 Telnet, 주소 카메라 IP, 포트 23. 사용자 root, 비밀번호 없음 |
| FTP | 윈도우 탐색기 주소창에 ftp://카메라IP, 또는 FileZilla. SD 카드 내용이 보인다 |

카메라가 WiFi 기능 화면을 나오면 연결을 끊을 수 있다. 접속이 안 되면 WiFi 화면에 머문 채로 시도해 본다.

## 키 할당 바꾸기

키 감지는 bin/nxkeys 다 (tools/nxmenu/nxkeys.c, NX-KS keyscan 바탕). 보통은 메뉴의 키 설정을 쓴다 (위 "키 조합"). 이벤트가 오면 conf/keymap 에 할당된 동작(scripts/<동작>.sh)을 실행하고, 할당이 없으면 scripts 에 아래 이름의 파일이 있을 때 그것을 실행한다 (메뉴에 없는 동작을 직접 만들 때). 스크립트는 백그라운드로 실행되어 도는 동안에도 키 감지가 멈추지 않는다.

| 파일 이름 | 실행 시점 |
| --- | --- |
| EV_<키>.sh | EV 를 누른 채 그 키를 누름 (EV 를 누르고 있으면 반복 가능) |
| <키>_<키>.sh | 같은 키를 1초 안에 두 번 (바로 앞에 누른 키가 같을 때) |
| <키>_PRESS.sh | 누르는 순간 |
| <키>_RELEASE.sh | 떼는 순간 |
| <키>_LONG.sh | 0.8초 이상 누르고 있음 (누르는 동안 한 번) |
| MODE_SAS.sh | 모드 다이얼이 SAS 를 벗어남 |

키 이름: EV, OK, AEL, UP, DOWN, LEFT, RIGHT, S1(반셔터), S2(셔터), MOBILE(WiFi), FN, DEL, PB(재생), MODE_SAS, MODE_SCENE, MODE_AUTO, MODE_P, MODE_A, MODE_S, MODE_M, MODE_C (모드 다이얼).

카메라 자체의 키 동작은 막을 수 없다. 예를 들어 OK_LONG.sh 를 만들어도 OK 를 누르면 카메라의 OK 동작도 일어난다.

새 동작을 메뉴의 키 설정 목록에 넣으려면 scripts 에 스크립트를 두고 scripts/actions.list 에 "스크립트이름|보일 이름" 한 줄을 더한다.
