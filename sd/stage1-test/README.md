# 단계 1 검증용 SD 구성

설치 패키지로 래퍼를 설치한 뒤, 이 폴더의 nx500ex 폴더를 SD 루트에 복사한다. 경로 전체가 동작하는지 확인하는 최소 구성이다.

```
nx500ex/
    boot.sh                 래퍼가 부름. 이전 실행 정리 후 keyscan 시작, log/boot.log 에 기록
    bin/watch.sh            블루투스 데몬이 사라지면 keyscan 정지 (블루투스 = 모드 스위치)
    bin/keyscan             NX-KS 2.55, 2.88, NXWA 가 써 온 것과 같은 바이너리 (md5 3bb2322589883308c488f72af0f6dffc)
    scripts/auto/00_hello.sh  켤 때마다 AF 보조광 1초
    scripts/EV_S1.sh        EV 를 누른 채 반셔터: AF 보조광 두 번 깜빡임
```

keyscan 은 Otto Kiksmaler 가 작성했고 상류 저장소(ottokiksmaler/nx500_nx1_modding)의 keyscan.c 가 소스다. 라이선스는 AGPL-3.0 이다.

## 확인 순서

| 번호 | 할 일 | 기대 결과 |
| --- | --- | --- |
| 1 | 설치 패키지 실행, 블루투스 ON | INSTALL OK |
| 2 | nx500ex 폴더를 SD 에 복사하고 배터리를 뺐다 넣은 뒤 전원 ON | 몇 초 뒤 AF 보조광이 1초 켜짐 |
| 3 | 전원 스위치 OFF, 다시 ON 을 5번 반복. 켤 때부터 불이 들어올 때까지 대략 몇 초인지 메모 | 매번 불이 켜짐 |
| 4 | EV 를 누른 채 반셔터 | 보조광 두 번 깜빡임 |
| 5 | 블루투스를 메뉴에서 OFF 한 뒤 EV+반셔터 | 반응 없음이 예상 (모드도 함께 꺼짐) |
| 6 | SD 를 PC 에 넣고 nx500ex 폴더 안에 빈 파일 DISABLE 을 만든 뒤 콜드 부팅 | 불 안 켜짐 (안전 모드) |
| 7 | 다른 SD 카드(nx500ex 폴더 없음)로 켜기 | 순정과 같이 동작 |
| 8 | 제거 패키지 실행 | UNINSTALL OK |

결과와 함께 SD 의 nx500ex/log/boot.log 와 nx500ex-state 폴더의 로그를 전달한다. 3번에서 매번 불이 켜지지 않으면, 켤 때마다 bluetoothd 가 다시 시작된다는 가정이 틀린 것이다. 그때는 keyscan 하나만 내장으로 옮기는 방안으로 간다.

## 블루투스 OFF 동작 원인 조사 (진단판)

지금 들어 있는 boot.sh 는 진단판이다. 다음을 추가로 한다.

- bin/mon.sh: 1초마다 keyscan, bluetoothd 의 생존과 상태, SD 마운트 여부를 확인하고 바뀐 순간만 log/mon.log 에 기록
- keyscan 을 debug 모드로 실행: 받은 키 이벤트를 log/keyscan.out 에 기록. keyscan 이 출력을 4KB 단위로 모아 내보내므로 키를 여러 번 눌러야 기록이 나타난다. 이 모드에서는 auto 스크립트 실행 때 SD 접근 LED 가 세 번 깜빡인다 (정상)
- 모든 기록 뒤에 sync 를 해서, 전원을 끄거나 카드를 빼도 기록이 남게 했다 (첫 진단판은 sync 가 없어 기록이 빠졌다)
- EV+반셔터: 기록에 표식(marker)을 남김

상태 기호: R 실행 중, S 대기(정상), T 정지됨, D 입출력 대기, Z 종료됨. wchan 은 대기 중인 커널 함수 이름이다.

### 준비

1. SD 의 nx500ex 폴더를 새 것으로 바꾼다 (bin/mon.sh 가 추가됨). 기존 log 폴더는 지워서 새로 시작한다.

### 절차

각 단계 사이에 10초씩 기다린다. 각 단계에서 EV+반셔터를 눌렀을 때 AF 광이 두 번 깜빡였는지 O, X 로 적는다.

| 단계 | 할 일 | 깜빡임 |
| --- | --- | --- |
| 1 | 블루투스 ON 상태로 전원 ON. 10초 뒤 EV+반셔터 | |
| 2 | 설정에서 블루투스 OFF. 10초 뒤 EV+반셔터 | |
| 3 | 설정에서 블루투스 ON. 10초 뒤 EV+반셔터 | |
| 4 | 설정에서 블루투스 OFF. 전원 스위치 OFF | |
| 5 | 전원 ON (블루투스 꺼진 상태). 10초 뒤 EV+반셔터 | |
| 6 | 설정에서 블루투스 ON. 10초 뒤 EV+반셔터 | |
| 7 | 설정에서 블루투스 OFF. 곧바로(3초 안에) EV+반셔터, 10초 뒤 한 번 더 | |
| 8 | 설정에서 블루투스 ON. 10초 뒤 EV+반셔터 | |
| 9 | 10초 기다린 뒤 전원 OFF | |

설정 화면 안에 있을 때와 촬영 화면으로 나온 뒤가 다를 수 있으니, 각 단계에서 EV+반셔터를 어느 화면에서 눌렀는지도 적는다.

### 전달할 것

- 위 표
- SD 의 nx500ex/log 폴더 전체 (boot.log, mon.log, keyscan.out)

### 기록으로 구분할 수 있는 것

| 관찰 | 의미 |
| --- | --- |
| keyscan.out 에 키 이벤트가 없음 | keyscan 이 키를 받지 못함 (입력 장치 문제, 정지 상태) |
| keyscan.out 에 "Combo EV + S1" 은 있는데 표식이 없음 | 키는 받았으나 스크립트 실행 실패 (SD 접근 문제 등) |
| mon.log 에 keyscan 상태 T | 누군가 프로세스를 일시 정지시킴 |
| mon.log 에서 keyscan 이 사라짐 | 종료됨 |
| sd:off | SD 가 언마운트된 상태 |

## 블루투스 = 모드 스위치 확인

| 번호 | 할 일 | 기대 결과 |
| --- | --- | --- |
| 1 | 블루투스 ON 상태로 전원 ON, EV+반셔터 | AF 광 1초, 조합키 동작 |
| 2 | 블루투스 OFF, 3초 뒤 EV+반셔터 | 반응 없음. boot.log 에 "bluetooth off: keyscan ... stopped" |
| 3 | 블루투스 ON, 5초 뒤 EV+반셔터 | AF 광 1초 (매번 새로 시작), 조합키 동작 |
| 4 | 블루투스 OFF 후 1초 안에 다시 ON, 5초 뒤 EV+반셔터 | AF 광 1초, 조합키 동작 (빠른 전환에도 꺼지지 않음) |
| 5 | 블루투스 OFF 상태로 전원 OFF, ON | 반응 없음 |
| 6 | 블루투스 ON | AF 광 1초, 조합키 동작 |
